### About Me

I am focused on Biomedical Engineering, embedded systems, and healthcare technology. My practical work involves experimenting with microcontrollers, connecting basic and biomedical sensors, and exploring wearable health-monitoring concepts.

- 🎯 **Areas of Interest:** Biomedical instrumentation concepts, basic physiological measurements, and sensor-based monitoring.
- 🔌 **Hardware & Interfacing:** Working with ESP32, Arduino, biomedical sensors, and basic environmental sensors.
- 💻 **Software & Web:** Writing basic firmware, building lightweight web interfaces using basic HTML and JavaScript for sensor display, and using Firebase for data storage.
- 💡 **Focus:** Building practical hardware setups to understand physiological monitoring and sensor integration.
