### About Me

Biomedical engineering practitioner focused on embedded systems, biomedical instrumentation, and Internet of Things (IoT) architectures. My work involves designing hardware prototypes, interfacing physiological and environmental sensors, and establishing real-time telemetry pipelines using microcontrollers and cloud databases.

- **Focus Areas:** Wearable health monitoring architectures, multi-sensor data acquisition, and embedded firmware.
- **Hardware Integration:** Interfacing analog and digital sensors (PPG, inertial, environmental) via I2C, SPI, and UART interfaces.
- **Data Handling:** Designing connected IoT data flows using ESP32/Arduino hardware paired with Firebase backends.
- **Prototyping Philosophy:** Developing modular, reproducible hardware and firmware testbeds for experimental evaluation (non-diagnostic research prototypes).
